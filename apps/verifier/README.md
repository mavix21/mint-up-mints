# Verification website scaffold

Generated with the official create-next-app 16.4.5 CLI using the empty App Router template, TypeScript and ESLint.

The generated Hello world page is the only page. MINT lookup, Stellar RPC reads, IPFS retrieval and validity checks are planned.

From the repository root:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
```

See the root README for project scope and status.
